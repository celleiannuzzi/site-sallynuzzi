\# Revisão de qualidade web



\## Código

\- Usar HTML semântico, CSS organizado e JavaScript sem dependências desnecessárias.

\- Evitar código duplicado e funções globais desnecessárias.

\- Validar links, referências a imagens, scripts e folhas de estilo.

\- Verificar erros no console do navegador.



\## Responsividade e acessibilidade

\- Testar diferentes larguras de tela.

\- Verificar navegação por teclado, foco visível e textos alternativos.

\- Conferir contraste, títulos e nomes acessíveis dos controles.

\- Respeitar a preferência por movimento reduzido.



\## GitHub Pages

\- Conferir se o arquivo de entrada está no local correto.

\- Usar caminhos relativos adequados à publicação em subdiretórios.

\- Verificar links internos e recursos estáticos.

\- Não presumir que rotas de um servidor backend funcionarão em hospedagem estática.

\- Não incluir tokens, senhas ou chaves privadas no repositório.



\## Ao concluir

1\. Resumir os arquivos alterados.

2\. Informar os testes executados e seus resultados.

3\. Sinalizar problemas que não puderam ser verificados.

4\. Não publicar nem enviar alterações ao GitHub sem autorização explícita.
